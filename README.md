
## Steps to run the slides

Forked from the following project
https://revealjs.com/installation/#basic-setup

This will allow us to write the document in markdown and present it in slides

```bash
git clone git@github.com:verilog-meetup/verilog-hackathon-education-kit-manual.git
```

```angular2html
cd verilog-hackathon-education-kit-manual && npm install
```

```angular2html
npm start
```
